# Sample data

This folder contains public synthetic data for demonstration purposes.

The file `synthetic_phosphorus_experiment.csv` was generated with simulated values and does not reproduce the original greenhouse experiment dataset.

The synthetic dataset mirrors the general structure of the private analysis workflow, including soil labels, phosphorus dose levels, extractor values, dry matter, plant phosphorus concentration, and plant phosphorus uptake.

Use this dataset only for public demonstrations, code examples, and workflow testing.
